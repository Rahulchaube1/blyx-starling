# Starling starter

Estimate resource capacity and actual occupied time from a booking schedule.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Starling** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
7
2
2
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/starling) · [View the release](https://github.com/Rahulchaube1/blyx-starling/releases/tag/v0.1.0)
